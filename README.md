## Опис проекту
Модуль системної діагностики інженерного середовища Python, дослідження просторових накладних витрат структур даних, кешу малих цілих чисел та аналіз інтервалу квантування потоків CPython (`sys.getswitchinterval`).

## Інструкція запуску
1. Створення середовища: `conda env create -f environment.yml`
2. Активація середовища: `conda activate ce_lab_env`
3. Запуск діагностичного скрипта: `python system_diagnostics.py`
